# 软件说明书（模板）

# 1. 概述
- 软件名称：CatalystOptimizationSystem
- 版本号：v0.1.0（示例）
- 开发单位/作者：
- 完成日期：
- 运行环境：Python 3.10；依赖 pandas/numpy/scikit-learn/scipy（可选 matplotlib）
- 功能简介：
  - 文献检索与抽取（Elsevier+LLM，可选 ICL）
  - 数据清洗与聚合（支持必需列/非零过滤/列名映射）
  - 缺失值插补评估（交互式/LLM 提参，评分导出 CSV）
  - 贝叶斯优化建议（支持权重/公式目标，可指定列映射）
  - API 与 CLI 双入口

# 2. 系统结构与模块
- 目录结构：
  - core/: extractor, validator, imputer, optimizer, imputation_workflow
  - utils/: config, logger, visualizer
  - api/: app（http.server）
  - tests/: 基础测试
  - docs/: 文档与软著材料
- 模块简述：
  - core.extractor：Elsevier 检索、全文获取、LLM 提取
  - core.validator：清洗/聚合/验证/非零过滤
  - core.imputer：插补工具与稳健缩放
  - core.imputation_workflow：评分、交互与 CSV 导出
  - core.optimizer：BO 建议（支持权重/公式）
  - api.app：/health, /extract, /suggest

# 3. 安装与运行
- 安装依赖：
  - pip install -r requirements.txt（示例；或按需安装 pandas numpy scikit-learn scipy）
- 命令行：
  - 清洗：python -m CatalystOptimizationSystem.core.validator input.csv --required ... --nonzero ...
  - 提取：python -m CatalystOptimizationSystem.core.extractor --elsevier-key ... --keyword ... [--icl ...] [--llm-key ...]
  - 插补评估：python -m CatalystOptimizationSystem.core.imputation_workflow --csv cleaned.csv [--llm-key ...]
  - 优化建议：python -m CatalystOptimizationSystem.core.optimizer --csv cleaned.csv --objective "sel + 0.5*conv" 或权重参数
  - API：python -m CatalystOptimizationSystem.api.app 127.0.0.1 8080
