# FusionLab r14：可选 HTTPS API 与私人访问令牌

日期：2026-10-08。用户明确选择连接已有 HTTPS API、使用访问令牌；默认仍为本地模式。运行源码冻结 `a0476da`，主功能提交 `33bf4af`、清理旧 SSH 死状态提交 `72a71c6`、不再把远程工作区标成“本地”的界面修复 `a0476da`，分别提交推送。

## 实现与使用

Settings → Compute location → Remote HTTPS API。填写兼容 FusionLab 协议 2 的 API **基地址**（不是 `/api/platform/info` 完整路由）和访问令牌；保存后重启。地址不预填。正常公共证书使用系统信任；私有 CA 可显式指定本机 PEM 文件，仍检查证书有效性和主机名，不提供关闭验证选项。

Windows 原生层用当前用户 DPAPI 加密令牌再存本地设置。设置读取只返回 `has_access_token`，不返回令牌或加密字节；输入框为密码类型，成功保存后清空。空输入保留同一基地址的令牌；更改基地址必须重新提供令牌，防止把旧凭据发送到另一服务。切回本地可在下次启动恢复本机模式；保存不改变当前连接。不在仓库保存私人服务器名、地址、账号、证书或凭据。

远程模式仅启动受桌面监管的回环转发进程，不创建本机科学执行引擎或项目数据库。现有前端仍访问回环接口、使用单独的本机随机会话令牌；远端访问令牌只在原生层和 Python 转发后端使用。转发保留现有项目、审批、运行、资源合同，不另建科学管线或客户端 DAG 状态。远端项目不会自动合并或迁移本机项目。

启动先验证 TLS、持令牌请求及完整 RuntimeInfoView 协议；拒绝错误令牌、无效证书或不兼容接口。请求只允许原平台 GET/POST 路由，转发原请求体和资源下载；本机令牌及 Cookie 不向远端传播，远端 Set-Cookie/跳转不返回或追随。写入超时不自动重放，因为远端可能已提交；用户应检查远端状态再重复操作。关闭桌面只结束自有回环进程，不管理远端作业。原 API 同时支持标准 Bearer 和现有 X-FusionLab-Token；认证策略提取为同一函数，未通过关闭认证接通。

删除未用于生产的旧 SSH 模块、端口/别名表单及其临时文件清理状态，仅保留旧 `ssh` 设置的读取兼容：不激活隧道，可在设置中选择本地/HTTPS 恢复。没有新增凭据哈希、签名或前端技术编号要求。

## 最终真实桌面验收与交付

最终 `a0476da` EXE 的原生桥未替换。服务器启动隔离的真实 FusionLab 后台、真实 TLS 证书和随机访问令牌，本机显式信任本次测试 CA，没有安装系统根证书或关闭 HTTPS 校验。API 测试服务源码为 `33bf4af`，其全部 Python 源码与最终版相同，后续两次修改仅为 Rust 死状态和前端页头。

实际完成五阶段：本地默认 → 表单保存远程地址/令牌 → 重启连接远程 → 再次重启保留远端项目 → 故意保存无效令牌后拒绝启动连接并在设置中切回本地。成功保存后的密码框为空，设置读取不含令牌/密文；配置文件未含明文，远端令牌不同于前端回环令牌。实际在远端创建并保存项目，通过前端导入 FASTA、确认、保存、下载原件逐字节一致；服务器 SQLite 的只读核验确认远端两次独立验收项目及原件确实存在，运行数 0。这不是模拟远程请求，也不是用户真实端点验证。

远程连接、远端项目重启和错误令牌阶段，本机原科学 SQLite 文件字节未改变。每阶段正常关闭后均 0 个自有残留进程；远端服务不因桌面关闭而退出。无匿名或本地自动降级；错误连接时仍能进入 Tools → Settings 恢复，不要求手工编辑设置。后端连通并不等于任意远端权限已验证，多租户权限仍由远端管理。

最终 EXE 另验本地 M5/F3（复用服务器 r13 原始合成软件阶段产物）、公开 24 链结构和 BCIF 四来源；41,136 原子/24 链及 1,714 原子/1 链、不填补指标空值、pLDDT 零值及原注释字节保留，实际注释关联表单通过。15 个嵌入资源字节一致，默认页面不显示原哈希/UUID/配置路径，无 CSP 违规、外部浏览器请求或页面异常。正常退出与重启保存通过、0 自有残留；117,333 ms 是完整功能探针总时长，不是纯启动基准。科学计算未在本机执行。

真实 Windows 文件夹选择另验通过，未拦截 filechooser、未 setInputFiles；两份嵌套原件、明确入口、类型化预览、确认保存、科学运行数 0 与正常退出均检查。首个私有 UI 探针无法用 UIAutomation 祖先找到弹窗；补充 Win32 所有者 HWND 链对照**精确自有主窗口句柄**后成功，不通过遍历或操作其他程序窗口放宽作用域。
