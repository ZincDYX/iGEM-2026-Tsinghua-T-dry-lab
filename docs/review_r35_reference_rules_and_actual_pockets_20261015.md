# r35：参考规则更新与真实 M1/M2 结果

## 当前结论

**M1/M2 尚未按原方案全部完成，现有证据不能证明原始湿实验构建在所有候选中结构最优。**

已有预测支持一个较窄的结论：所用 OC、DMT 融合的预先冻结酶核心与未融合预测核心相近。OC 的 294 个核心残基在 5×5 模型比较中 CA RMSD 为 0.081–0.273 Å，DMT 的 191 个核心残基为 0.097–0.488 Å。这是预测模型的 apo 核心比较，既不是 25 个独立动力学重复，也不证明催化化学、招募、完整组装或 ER 膜相容性已通过。

不预先指定获胜序列，不根据结果改变比较组、阈值或权重。未完成、未收敛和缺失值均不能作为支持原始构建最优的证据。

## 本次输入与规则

采用用户提供的 `M1_M2_三项规则与参考状态_20261015.zip`，27 个 manifest 校验项全部匹配。原输入、工具、权重和计算数据保留在私有工作区，不纳入公共源码和代码 bundle。

1. 在原 `m1_prioritization.py` 中增加明确选择的 `initial_equal_weight` 模式，不复制一套独立排序系统。对相同预声明用途/融合背景、条件、长度、适用范围及工具版本的完整去重组，计算：

   `z_j = (ascending_average_rank_j - 1) / (n_unique_complete - 1)`

   `S_initial = (z_FuzDrop + z_catGRANULE2016 + z_PScore) / 3`

   n 必须至少为 2。原始输出重新解析后才能使用；缺项不补零、不只平均剩余两项；别名不增加样本数。参考成员、精确序列、原分数和分组保存在 manifest。不同组不输出伪装成全局排序的扁平冠军名单。Pareto 仅作辅助诊断。旧的原方案加权模式保留明确名称，不冒充新三路等权。
2. 新模式只旁列软审查项，不再按风险项数量生成总体低/中/高风险。κ、SCD 和 sticker 特征不被强行赋予统一危险方向。
3. FuzDrop 网站协议标识不能冒充已知服务器算法版本。当前原始数值可用，但服务器没有公开二进制版本，正式比较保留该缺项，不擅称使用了某个论文版本。
4. 新增显式选择的 2022 论文 DPR 描述性重分析：pDP≥0.60 连续≥10 aa。它不再误用 25 aa，不改变全序列 pLLPS，不被写成当前网站版本认证或 M1 通过。
5. 已采用氧化 FAD、原 C36 未修饰基块 −2，以及反应前高自旋 Fe(II)/2OG 二阴离子的参考选择。这些选择不等于目标酶的共价补丁、金属配位或最终体系电荷已验证。

## 新增 P2Rank 与化学准备证据

原版 P2Rank 2.5.1 和对应 Java 运行环境已取得并在计算服务器原生执行。对 OC ΔN 融合、OC ΔN 未融合、OC WT 设计参考、DMT 融合和 DMT 未融合各五个精确模型使用作者 `alphafold` 配置，避免将结构展示 B-factor 当作晶体温度因子特征。

原始预测 CSV、完整残基邻域、口袋坐标、分数、候选位点成员关系、逐模型绑定和命令记录均保留。`igem.m2.read_pocket_candidates` 在真实 stdio MCP 中调用，与共享实现返回一致结果；CLI/工作流复用同一解析。新增 `prediction.p2rank` 复用私有运行配置及通用原生工具适配器，在持久执行器中对一个已计算目标真实验证，十个口袋与原批作业一致；这不是新增独立模型。该验证由已获授权的维护端执行，不开放浏览器提交私有绝对路径，也不冒称全部前端文件绑定已完成。源结构/输出被替换、残基不属于精确模型时拒绝该证据。原始预测是机器学习候选，不是目标配体姿态、已确认催化口袋或完整拓扑。

同时导出十个 DMT 模型中 H228、D230、H285 候选供体的 120 条实际原子距离，保留两种 His 环 N 与 Asp 羧基 O 的可能性。没有把候选残基中心当铁坐标，也没有凭距离生成金属力常数。

对新增 2,625 个完整 DMT 刚体招募姿态，已继续计算每个完整 24 聚体的 24 个宿主位置，逐个保留对其他 23 个完整融合亚基的最短重原子距离和最近原子身份，共 63,000 条。原模型、模板和变换逐一绑定，完整酶及全部亚基没有截短。预声明的首个情景另以穷举 504,877,416 个原子对独立核对，所得 0.1235346898 Å 与空间树算法一致。

七个新融合候选的最短距离范围分别为：FUS-LC 0.037–1.554 Å、FUS-ND 0.058–3.667 Å、CHARGEPAIR 0.019–0.593 Å、LOCAL90 0.016–0.650 Å、SHUFFLE 0.029–0.911 Å、YHIGH 0.025–1.077 Å、YLOW 0.043–0.858 Å。这里的范围是每个候选 9,000 个条件性放置的最短距离范围，不是置信区间、独立重复分布或总体风险分数。部分姿态存在近乎原子重合，不能直接交作可用复合物；仍需柔性采样、松弛和正式口袋/共占位分析。没有新增淘汰 cutoff，也不按最有利构象认定任何构建最好。

## 四个参考膜的真实状态

四种配方、稀有 CL、叶层计数、来源构象和原 C36 拓扑均保留。旧六个无进展的 PACKMOL 排布尝试已停止，未删除原日志/坐标。新增可选分组复用原始构象的初始化方式，减少独立 molecule type 数，并设置仅针对初始排布的超时。该超时不缩短科学 MD 预算，不放宽 2 Å 排布距离或力场。

四个分组尝试及随后四个刚体取向尝试，均在各自 600 秒内未收敛，已记录失败。已检查失败输出的实际头基位置，而不是只看进程是否结束。新增可选的保手性刚体取向和官方 PACKMOL restart 初始化：按原始盒子/头基参考面分层交错布置，正确转换为 PACKMOL 使用的原子算术质心平移；这些是初始位置，不是 MD 位置约束。四个 900 秒有界网格重启尝试正在执行，**截至本报告快照，没有新的膜 EM/NVT/NPT/生产通过结果**。没有扩大盒子、删除脂种/氢或放宽 2 Å 排布距离。GROMACS 退出 0、文件存在或 Fmax 非有限都不能视为通过。EM 判据按任务书严格采用 Fmax<1000 kJ mol⁻¹ nm⁻¹，等于边界也不算达到。

后续仍需解决原子排布与实际完整 cage 的面积/锚位准备。2000 分子只是裸膜计数参考，不能证明足以容纳完整 24 锚体系。未知其他 10% 不阻塞这四个已批准参考分支，但它们也不能被称为完整实测项目膜。
