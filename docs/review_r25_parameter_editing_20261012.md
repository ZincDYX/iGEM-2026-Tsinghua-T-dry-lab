# r25：去掉重复入口，真正接通参数编辑

本轮重新核对 2026-10-11 的 r23 Results / formula execution review。r24 报告里的“删除重复入口”和“参数可编辑”描述不充分：顶部 Assistant / Jobs 仍重复；历史参数没有就地进入草稿的入口，保存参数还会清空当前选择；自定义公式变量另有一套表单。此次纠正这些实际问题，不把旧验收代替新版验收。

## 修改与操作

- 删除顶部 Assistant / Jobs，只留 View 菜单。显式 Review 仍展开提案，执行或失败时 Jobs 仍显示。
- 历史 Workflow / Parameters 有 **Edit current draft**；恢复同一份持久草稿，不反复创建副本，不修改历史运行。它编辑的是当前项目草稿，不将它伪装成历史快照。
- 模块绑定和自定义标量都使用 Parameter / Value / Unit 表。点击值，直接在行内编辑、保存。保存走真实后端，不清掉工作流或选择；来源只读。
- 正式参数创建待审核的新记录，保留原记录。未审核的替代值明确标记，实际阶段阻止悄悄退回旧值；审核仍使用原来的单位、身份、条件和来源验证。
- 不将有原始测量来源的直接测量误认为派生计算；model_fit 才作为计算结果不可直接覆写。覆写不继承旧置信区间或批准。
- 修复真实安装版发现的保存缺陷：后端将已验证的默认字段一次性保存；旧的部分记录不会因反复生成 created_at 而误拒绝追加新版本。原始值、单位和来源不可覆写的检查仍保留。没有待审核记录时不常驻展示空审核表单。
- 标量参数修改创建新的可执行方法版本，并更新当前节点的实际绑定；保留其他节点和依赖。公式预览和计算来自同一个受限 AST，旧运行不查询当前草稿。
- 新方法编辑不再提供容易误认为能执行的独立 LaTeX 表单。展示原始完整式、新版本和差异；初次绑定只需参数名、值、单位和一个明确的来源，已有绑定保留其来源。表达式引用或量纲错误由原校验器拒绝。
- 正式 M1–M4 从 Tools → Run 自动带上已有科学计划及必需上游模块；不重复绑定同一输入，仍需 Review / Accept / Start。
- 纯 ER 模型不再显示它不消费的胞质参数。ER 结构化模型内的参数按真实引用展示为只读，说明必须修改模型和匹配证据；不会接受只改 Registry 却继续算旧嵌入值的假编辑。

## Review 其余项目核对

17 候选的有类型 M1 汇总、M2 缺数据专用视图、M3 三个主要招募量、M4 当前情景目标曲线与分页 Data、Sources 去重、删除左栏/伪 Terminal、一个工具列表、简洁 Skills/插件权限、正确区分输入路径和输出目录继续保留。不修改原始科学式、阈值、单位、数值精度或求解容差。M4 任意速率律/网络编辑不是标量编辑能力，原基线和未支持的结构化模型保持明确只读。
