## 合并与删除，不扩建框架

- 删除 PrecheckPanel 自己的请求、结果、错误和 pending 控制；它只显示共享结果，缺项表由一个组件复用。
- 公共资源字段归入一个基类，不在图片/结构/曲线/扫描/表格五处重复定义状态。
- 输入问题定位复用已有导航，计划失效复用已有控制器；没有新增导航/检查控制器。
- 删除已不再用于逐残基查询的 SQL 表达式索引创建；完整索引按批处理验证，渲染按身份 Map 查找，不逐原子扫描所有注释。
- 目录复用内容检查已经解析的 JSON；不重复解析同一目录项。坐标预览不再无谓验证/装载注释；已验证 FASTA 不在每次翻页重解析。
- 将资源身份、导入指纹和执行预算/边界移入可展开 provenance/scope；保留与当前错误有关的就地提示。

保留的是有实际作用的边界：会话和项目授权、原件完整性、源绑定、预算、科学证据门控。它们不是为了页面变简洁就可以删除的设计。
