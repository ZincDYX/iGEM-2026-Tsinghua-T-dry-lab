## PR 1：公开边界与认证

新增明确 public view 和独立私有 runtime profile 存储。项目/节点/运行/产物视图不返回工具命令、部署目录、原始节点输入、内部数据库行或绝对路径。文件通过登记的逻辑身份与项目归属核验。原科学文件/hash 保留，秘密或私有路径原文件的下载被隔离，不通过字符串替换伪造原 hash。

运行 profile 由维护者私有集成接口写入，HTTP 科学项目不接受 `tools` 运维字段。profile identity 单独进入运行绑定，版本变化要求新运行。旧记录保留，公开读取经投影；没有迁移真实凭据。

节点和 HTTP 错误返回安全 code、说明与 diagnostic_id，原文留私有诊断。受信任插件的环境能力需要维护者按源码 hash 单项授权，不自动兑现 `secret_env`。实际子进程、ensurepip/pip 都使用最小环境；已知秘密输出不发布为有效产物。venv 仍不是 OS 沙箱，没有声称阻止恶意插件读取同账户主机数据或外传。

默认后台必须认证；匿名开发模式需显式 `--dev-anonymous`，只能绑定回环。移除 artifact query session token，下载改带认证头的 fetch/Blob，并校验项目归属。远程桌面尚无受控认证会话提供者，因此明确阻断，不能以 SSH/匿名 HTTP 成功宣称生产可用，也不访问实际 SSH 配置来完成本轮测试。

基础后台不再同步等待 MCP discovery；能力异步显示 checking/ready/unavailable。Tauri 自定义 commands 使用 AppManifest 和仅限内置 main 窗口的能力文件，不授权 remote origin/shell/fs。参考 [Tauri capabilities 官方说明](https://v2.tauri.app/security/capabilities/)。

发布脚本改运行时允许列表；完整源码/测试仍在 code bundle，不全塞入程序。import check 禁止写 pyc；在清单前固定文件，不在清单后修包。最终包仍须另行实际验收，不能把脚本修改当成包已经重建成功。

实际软件测试：6 项 HTTP/公开边界与文件身份测试、3 项真实标准库插件反例、9 项前端原有测试通过。首次 pytest 因默认 Temp 权限在 setup 阶段失败，换全新独立目录后暴露一项跨平台路径检查缺陷，加入 POSIX/Windows 双路径判据后上述安全断言通过；没有删断言。TypeScript 编译通过。后续批次会添加运行控制、分页和完整工作台 E2E。

## PR 2：正式来源与真实控制

正式 M1–M5 DAG 仅接冻结项目和前序节点登记的 artifact 身份。执行时重新检查成功状态、原文件 SHA-256、项目/运行/快照/阶段/schema，并从这些字节解析 records；客户端 evidence_ready 或 literal records 不能替代来源。原 stage 内部二次科学核验保留。

一个后台 engine 的多个运行共享有界线程池及 GPU 锁，运行控制器另有有界队列；这不是跨进程/集群调度。内存上限尚不支持，声明内存限制的策略拒绝，而非显示已生效。执行范围、阶段数量、前后检查点、工具调用数和派发截止时间进入审批 hash。暂停等待当前 handler 完成；取消后不发布晚到结果，未声称中断 ODE 或任意工具进程。

实际测试：22 项新增软件控制/来源/隐私测试通过，7 项原有 fork/join、fan-out/map、重试、租约与实际子进程崩溃恢复通过。初次测试暴露检查点提前触发，修复后通过；另外六项失败属于软件 fixture 未填 typed 配置必填列表，补齐空列表，没有读取或运行该科学配置。失败 XML 与复测 XML 分开保存。

## PR 3：轻量读取与短事务

新增项目摘要、带原子事件版本的运行摘要、游标事件、单节点候选分页、登记轨迹切片和显式科学投影导出。状态不包含项目内容、节点 output 或轨迹；历史查询有上限，项目历史查询走实际索引。原 artifact 字节不改，科学投影导出明确声明非原字节，并分别提供原始与导出 SHA-256。M4 adapter 的轨迹改引用原文件，新包裹 schema 为 scientific-stage-v2；科学 records、数值和原文件不改。

快照文件/源码读取和 JSON/hash 准备在写事务前，事务内重新核对项目 revision/输入/工作流绑定再保存。源码字节仅在同一次核验操作中缓存，不跨运行以 mtime 或工具名充当 hash。新增非重叠、自调度、AbortController/版本判定的前端轮询函数，工作台接线在 PR 4。

22 项相关后端软件测试通过，其中覆盖 1,000 候选分页、500 KB 项目不进入状态摘要、10,000 事件的实际 EXPLAIN 索引计划，以及真实并发修改发生在快照准备期间时返回 409 且不创建运行。该数据规模不是生产性能承诺；未测真实大型轨迹读取延迟，轨迹接口仍需核验并解析单个原文件。

## PR 4：工作台、提案与迭代

默认中央显示真实 DAG/阶段表，左项目与历史树，右 Agent/证据/诊断，底任务/事件/审批动作。布局、密度和主题只在本机保存，不进入科学审批 hash。原巨型 App、旧样式、绝对路径科学输入面板和无调用者的类型断言 HTTP helper 移除，Git 历史保留可恢复；输入、项目草稿 reducer、运行轮询、协议适配和结果视图分开。

公开 Pydantic 模型为唯一 wire schema，机械生成 TypeScript 与静态校验器；未知协议、额外私有字段、缺状态和字符串数值被拒绝，不在浏览器补默认值/强制转换。生成文件较大是实际 schema，不是手写重复业务。构建时合并同名同内容定义，并拒绝冲突，保留严格 CSP，不加入 unsafe-eval。依据 [Ajv 静态校验官方说明](https://ajv.js.org/standalone.html)。当前生产 JS 主文件约 679 KB（gzip 122 KB），仍有 chunk 大小警告，未声称真实低端机启动性能已优化完成。

模板明确不调用 LLM。维护者可注入现有 HybridLLMPlanningBackend；收到用户数据出境同意后，公开目标/文件身份进入原语义解释与确定性编译器，再转同一 durable workflow engine。模型输出只作提案；接受提案不执行、不审批参数。用户 DAG 同样先验证、产生提案并单独接受。提案/批准/执行请求动作持久保存；真实 stage 事件/产物在原运行账本。前序无可核验复用时明确补依赖；用户禁止重跑却无可信前序时阻断，不偷换范围。

下一阶段、目标依赖闭包、阶段前后检查点、工具调用预算和派发截止绑定工作流审批。继续/选中节点重试沿用冻结输入、工具和幂等核验。暂停等待 handler 实际结束，取消不发布晚到结果；没有声称强杀数值工具。停止当前提案与取消运行是两个操作。冻结输入迭代产生新项目，复制已核验原文件，保留父快照身份；保存差异按真实 ProjectInput/下游闭包判受影响阶段，不凭字符串猜阶段，也不自动跨运行复用。科学项目目前整份配置绑定，微小科学字段变化会保守影响所有相应阶段；未宣称完成细粒度可复用依赖。

输入用上传/文件夹/逻辑 ID。科学条件只有 config.experimental_context 为权威；普通备注不参加计算。M5 后端 typed 绑定只返回草稿预览，须保存、重新审阅，不能自动批准拟合值。结果按实际 tool/schema/formula 分版本：M1 当前页候选矩阵、M2 原参考与几何指标、M3 浓相/稀相/自由/结合/容量/守恒分列、M4 原值和按需轨迹、M5 QC/候选/条件来源。缺失不补零；静态负筛不升级实验确认。F2/F3 显示原记录，不在前端生成排名或计算新值。完整记录展开时才 stringify，授权科学导出另有身份。

最终实际软件证据：35 项 HTTP/来源/预算/索引/提案/崩溃恢复回归通过，另增空测量 M5 正向绑定测试后 7 项规划/绑定测试通过（与 35 项有重叠，不相加宣称 42 项独立测试）。12 项 Vitest 与 TypeScript/生产构建通过。严格 CSP 的生产页面真实 HTTP E2E 通过：401 认证反例、真实 hybrid 编译器+审批账本+假 handler、四个阶段边界、缺数值、按需原值、授权导出、冻结迭代/保存差异/重载，以及 1280×850、800×650 截图。该测试仅模拟 native connection 返回假会话，不等于 Rust/真实模型 API 验证。

软件 fixture 的科学输出全部显式 numerically_solved=false、evidence_ready=false、software_fixture_only，没有运行原科学求解器。初次差异测试漏计 revision、误写 temperature_C（正确字段 temperature_c）、漏计模板的 M5，均修正 fixture 与 oracle；失败记录和复测 XML 分开保存。原式与科学参数文件本轮未更改；完整科学参考回归未在本机运行。
