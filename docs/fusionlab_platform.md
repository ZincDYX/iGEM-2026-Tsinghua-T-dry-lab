# FusionLab 工作区与实现边界

当前安装、启动、自行打包和结果复现的唯一操作说明见 [README](../README.md)。本文件解释架构，不维护第二套安装步骤。

## 一个工作区

Inputs、Workflow、Results 是唯一的主导航。项目在顶部切换；Results 页头选择运行版本和结果对象。默认没有左栏、Scientist/Developer 模式或没有执行能力的 Terminal。Assistant 按需展开；Jobs 提供执行状态、实际错误和事件，不将 map 子任务列成普通科学结果。

Inputs 分为 Biological data 和 Plan / configuration。一次导入可以包含多种文件，登记成一张对象表。选择序列或构建后才显示对应内容、角色或声明修改；不为所有对象打开通用 schema 表单。新建序列筛选计划仅选择已导入的蛋白 FASTA。复杂 M2–M4 模型使用完整计划及其真实证据导入，不猜测缺失参数。来源核验与科学审批仍须明确完成。

Workflow 的模块参数只显示当前模块消费的 Parameter、Value、Unit。值修改和选择已有兼容来源都会产生未审批的新参数版本，保留旧记录；派生量不可随意覆写。必需参数缺失时回到 Inputs 添加证据。来源只读，不要求重新填写 DOI、哈希或审核字段。现有参数审核操作仍由后端验证单位、适用条件与证据。

正式方法保留完整原式，只读展示。Edit method 创建独立版本；显式标量 expression 通过受限 AST 和量纲检查，数学预览由同一表达式生成，禁止 eval/exec。纯排版版本明确不可执行。它们不替代正式 M1–M4，不获得原方法的科学验证结论，也不是任意 LaTeX/ODE 自动求解器。

## 后端职责

本地模块化单体：Project 保存人工输入，Workflow 保存有类型的绑定与依赖，Run 固定不可变输入/方法/工具/环境，Artifact 保留原始文件与上游记录。SQLite 保存状态与租约；已完成 shard 可恢复，非幂等的外部作业须先核对。前端不承担文件权限、凭据、执行许可或来源认证。

静态 fan-out、动态 map 和有序 gather 使用有界并发。节点只收到已解析输入及执行上下文，不直接读活的全局 Project。插件使用独立进程与锁定依赖的独立 venv；只安装明确受信代码，venv 不等于安全沙箱。共享部署仍需管理员授权。Skills 是可导入/导出 Markdown 的规划指令，不授予文件、网络或命令权限。

计算内核与调度分离。正式序列、几何、平衡、瞬态和稳态仍调用原有审查实现；真实 stdio MCP 连接不由直接本地函数调用冒充。可选 HTTPS API 连接使用本地设置中的访问令牌；仓库不包含私有部署地址、密钥或默认实验室服务。

## 结果与真实工具

M1 按候选显示已算特征、原规则判定与实际缺项；map 子步骤只在 Jobs 中诊断。M2 缺融合结构时不画空指标或虚构 3D 模型。M3 默认为 dense 总浓度、dilute 游离浓度及 dense 分数，比值单列。M4 显示实际目标曲线，Species / Phase / Quantity 分开选择，同单位才可叠加。Data 显式分页查看，Sources 和导出保留真实记录。显示舍入不修改计算或 CSV 精度。

同一 Tools 列表区分已注册、未配置、已配置未验证、实际输出并解析成功及真实失败；Run 绑定已选序列并进入正常确认流程。安装不等于许可、配置不等于真实作业、成功作业不等于科学输入可用。

受许可工具、缺失融合模型、未核验的实验参数及完整 ER 输入仍可阻断对应方法。合成演示只证明该输入下的数值链可运行，不构成湿实验验证；当前情景与整批状态分开，E3 缺项不得覆盖已求解的 E1。
