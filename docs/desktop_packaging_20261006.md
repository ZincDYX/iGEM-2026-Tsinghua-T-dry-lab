# Windows 桌面便携版

本轮只改桌面封装、连接选择和部署记录的可移植性，不更改 M1–M5 科学公式。默认本地 Python 后台与本机 SQLite；内置 React 生产页面，原生独立窗口。设置页的远程 SSH 为可选项，不内置服务器名称、地址、用户名、凭据或部署目录。

## 包装与边界

`FusionLab.exe` 使用同目录 `python/python.exe` 与 `resources/src`，不依赖构建机源码路径或全局 Python。使用完整目录或 ZIP，不能只复制 exe。后台沿用原有服务、stdio MCP 和持久工作流，Windows Job Object 在关闭或异常退出时回收后台/插件子进程。用户数据库及连接设置不放入程序目录。

设置页选择本地或用户 SSH 别名，保存后重启生效。默认不调用 SSH；没有默认远程主机。远程模式仅启动自己的隧道，不启动/停止服务器后台，不继承用户配置中无关的转发或会话命令，不关闭其他隧道。需要用户已信任主机与可用非交互认证，不自动跳过主机密钥验证。启动失败显示具体错误，设置页仍可用。

本机 SQLite、设置及日志使用 Windows LocalAppData，不作为漫游数据。后台就绪通知使用父子进程管道，只发送随机回环 URL，不把认证 token 写入通知。不使用用户目录中的临时文件替换作为启动 IPC：实际 Windows 用户目录复测中曾返回同目录替换 WinError 17，具体文件系统/加密过滤器原因未确定。测试目录通过不能替代默认用户目录的实际启动验证。

运行时采用 [Python 官方 Windows 3.13.13 发布目录](https://www.python.org/ftp/python/3.13.13/) 的 x64 embeddable 包，按匹配 CPython ABI 附带已安装依赖与许可证；不携带 editable 路径或原始用户项目。打包脚本生成源码/运行时逐文件 SHA-256 清单和依赖版本记录。平台前置要求参考 [Tauri Windows 分发说明](https://v2.tauri.app/distribute/windows-installer/)；本轮使用已有 WebView2，不修改系统浏览器。

不随包提供许可预测器、全部外部工具/GPU 权重或私有作者数据。默认本地软件可启动不等于所有真实工具自动作业、论文复现或项目实验验证已完成。科研回归与参考复现仍在独立验证环境执行；本机仅构建软件、核验后台启动和实际桌面页面，不做本轮科学复现。

本地启动实测曾因 OpenBLAS 默认并行线程的内存分配失败而中断 MCP 发现。桌面后台默认单 BLAS 线程（已有 OPENBLAS/OMP/MKL 用户配置优先），MCP 只白名单传递对应运行时控制，不继承桌面 token/API key。此项是资源默认值，不改变科学方程；普通服务器运行未指定线程时保持原语义。原始启动错误保留在交付记录，不能用 mock 工具目录替代真实 stdio 发现来绕过故障。

## 仓库信息清理

当前工作树的历史部署报告改用通用环境变量，论文来源链接、已报告数值及科学限制不改；部署诊断/证据脚本改为显式 CLI 输入或当前 Python，不硬编码私人机器目录。部署报告改为通用文件名，旧完整记录在仓库外保留。

本轮不改写已发布的 Git 历史。历史提交/旧 bundle 可能仍包含早期记录，不能将当前工作树清理说成历史信息已经彻底删除；若需要清理远端历史，需要另行明确授权和协作方协调。

最终 exe/ZIP 哈希、启动关闭、默认本地和可选远程连接结果在仓库外的交付验收记录中保存，避免把私人实际连接信息回填源码。Rust 连接测试不等于完整 GUI 测试；以实际打包产物的窗口检查为准。
