# r7 workbench and offline viewers

Scope: r6 PR B/D and the PR E client. Public UI/native/planner messages are
authored English strings; user inputs and original evidence text are retained.

- File/View/Tools/Help menus; Import/Save and contextual Check/Review/Start/
  Resume command. Pausing/cancelling addresses the selected frozen run.
  Settings/Plugins are maintenance menu pages, not primary research documents.
- Input tree links to actual sections; missing-input rows locate the appropriate
  input section. Detailed scientific parameters remain reviewed evidence, not
  UI-generated defaults. Plans use an intent-generation lifecycle controller.
- Selected result boundaries reset on run/node/attempt/artifact/page identity.
  M3 has a phase/free/bound enzyme matrix; M4 quantities, residuals, fluxes and
  registered F2 results retain their own meanings. No chart-side solver/ranking.
- Plotly strict 4.1.2 and Molstar 5.13.0 are locked, local, lazy chunks; fflate
  0.8.3 carries original binary folder bytes. No CDN/remote structure services.
  CSP adds blob images but no unsafe-eval, object/frame or external scripts.
- Series plot and table read identical bounded SQL pages, retain null versus
  zero, and link selected points. PDB/mmCIF views load authorized coordinate-only
  projections, use model/chain/residue/insertion identity and show only registered
  fusion/reference/pocket/pLDDT sidecars. No B-factor-to-confidence conversion,
  automatic reference alignment or invented assembly. WebGL failure retains
  residue tables and original download. Plots, React roots, GPU contexts and
  blob URLs are disposed on resource change/unmount.
- Authorized lineage comparison is paginated/batched and displays source
  identities, frozen input differences and formal comparability reasons. It
  does not turn different construct/condition/unit IDs into automatic ranking.

TypeScript and production build pass. Main JS is about 873 kB (gzip 142 kB);
Molstar ~3.56 MB and Plotly strict ~4.97 MB are loaded only when opened.
The build-size warning is retained, not disguised as a solved performance issue.
No model weights are installed. Viewer dependencies are MIT-licensed; licenses
and source versions must accompany release documentation. A complete dependency
CVE/SBOM audit, clean-machine installation and code signing are not established.

Browser and genuine native CSP/restart acceptance are recorded separately.
Synthetic coordinate/series/pixel samples are parser/display inputs, not science.
Scientific numerical/author regression remains server-only. The seven scientific
core files are unchanged; this is a byte identity claim, not model validation.
